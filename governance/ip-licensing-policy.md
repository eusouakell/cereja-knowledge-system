# IP and licensing policy

Status: v0.1.

The Cereja ecosystem contains different kinds of intellectual assets. They do not all need the same licensing model.

## Principles

1. **Public does not automatically mean open-licensed.**
2. License by asset type, not by habit.
3. Preserve upstream attribution and license obligations.
4. Keep strategic differentiation, monetization hypotheses and competitive analysis out of public repositories unless there is a deliberate reason to publish them.
5. A public reference should show provenance and influence without exposing the full internal research notebook.
6. Do not change licensing on collaborative work without checking authorship and contributor rights.

## Current policy

### Núcleo / Cereja Knowledge System

Status: **source-available for reading; no open reuse license**.

Public:
- canonical system contracts;
- public-safe evidence;
- concise external references;
- acknowledgements;
- design/accessibility principles.

Private:
- competitive deep dives;
- pricing or monetization hypotheses;
- positioning deltas;
- offer-productization logic;
- private/client research;
- unreleased strategic experiments.

### Flame Design System

Status: **no open reuse license**.

Flame is a core Cereja asset. Public documentation can explain principles and implementation decisions, but no blanket permission to reuse or commercialize the system is granted.

### Cereja Editorial Engine

Status: **no open reuse license while the operating model is under validation**.

Revisit after real publishing cycles clarify what should be open, what should be reference implementation, and what should remain proprietary.

### Context Engineering for Marketing

Recommended public-research license: **CC BY-NC-SA 4.0** for original research/documentation, with third-party material excluded and separately attributed.

### Marketing Context System

Do not apply one license to the whole repository yet.

First separate:
- executable source code;
- tests and utilities;
- documentation;
- skills;
- original methodology/framework material;
- third-party adaptations.

Then license each class deliberately.

### Collaborative projects

Bússola and similar collaborative work require contributor/origin review before any licensing change.

### Forks

Forks retain upstream licensing and attribution. Do not replace an upstream license with a Cereja license.

## Review trigger

Revisit this policy before:
- selling a system derived from these repositories;
- releasing an installable package;
- accepting outside contributors;
- publishing a template library;
- making a methodology claim;
- changing a repository from private to public;
- licensing code and documentation differently.
