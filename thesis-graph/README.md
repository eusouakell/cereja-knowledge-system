# Thesis Graph

Lifecycle:

```text
signal
→ question
→ hypothesis
→ working-thesis
→ published-thesis
→ challenged
→ revised
→ retired
```

Each thesis should record:
- ID and statement;
- why it matters;
- evidence and counterevidence;
- first observed / last reviewed;
- where it was published;
- related theses;
- founder notes;
- revision history.

A published statement is not permanent if the thesis later changes.
