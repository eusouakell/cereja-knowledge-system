# Originais para ingestão

Coloque aqui PDFs autorizados para processamento local. Os originais são ignorados pelo Git por padrão: direito de leitura não implica direito de redistribuição.

Para publicar um original, confirme a licença e adicione uma exceção específica ao `.gitignore` em PR. Nunca inclua arquivos internos da empresa ou de clientes.

O comando de ingestão preserva os bytes do original e cria apenas um registro de procedência em `sources/`. Não extrai nem resume o PDF.
